# Contributing

Thanks for helping improve repomark.

## Setup

```bash
git clone https://github.com/topdaily-dev/repomark.git
cd repomark
npm test
```

## Guidelines

- Keep the CLI dependency-free (Node built-ins only)
- Add or update tests in `lib/*.test.mjs` for behavior changes
- Use Conventional Commits (`feat:`, `fix:`, `docs:`, `test:`)

## Pair programming

Add a co-author trailer when work is shared:

```text
Co-authored-by: Name <id+username@users.noreply.github.com>
```
